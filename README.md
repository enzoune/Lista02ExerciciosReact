# ⚛️ ReactJS Arrays & State — Módulo de Exercícios Nível 2

## 📝 Descrição do Projeto
Este projeto compõe o segundo nível da formação profissional de Desenvolvimento Full-Stack no Instituto PROA, com foco exclusivo na manipulação de estruturas de dados e arrays com a utilização de `props` em ReactJS. O código implementa resoluções para desafios práticos de gerenciamento de coleções, como renderização de listas, filtragem de dados e acesso a índices específicos. A atividade resolve a complexidade de transpor arrays estáticos para componentes visuais dinâmicos, consolidando a compreensão sobre imutabilidade e a sintaxe de chaves `{}` para a renderização baseada em lógica de programação.

## 🛠️ Tecnologias Utilizadas
* **ReactJS:** Biblioteca voltada para a criação de interfaces baseadas em componentes reativos.
* **JSX:** Extensão de sintaxe que possibilita a inserção de lógica JavaScript diretamente no markup da aplicação.
* **JavaScript (ES6+):** Uso de métodos de arrays, constantes e desestruturação de dados para operações de processamento.
* **Node.js:** Ambiente de execução para gerenciamento de pacotes e servidor local de desenvolvimento.

## 🚀 Competências Desenvolvidas

### 🧠 Hard Skills
* **Manipulação de Arrays:** Domínio de métodos essenciais para leitura e extração de dados contidos em coleções, incluindo o acesso direto a índices e propriedades de objetos.
* **Renderização Dinâmica:** Aplicação prática da renderização de listas no React, garantindo a exibição precisa de conteúdos variados em tela.
* **Lógica Declarativa:** Integração de estruturas condicionais e de repetição dentro do fluxo de trabalho do React, substituindo métodos imperativos por fluxos mais eficientes.
* **Estruturação de Dados:** Organização coerente de coleções de dados para otimizar a manutenção e a legibilidade do código-fonte.

### 💼 Soft Skills
* **Pensamento Analítico:** Capacidade de traduzir requisitos de negócios e listas de exercícios abstratas em componentes de software testáveis e funcionais.
* **Organização e Documentação:** Manutenção de um código limpo e estruturado, facilitando a interpretação do fluxo de dados por terceiros ou em revisões futuras.
* **Resolução de Problemas:** Aplicação de boas práticas na depuração de interfaces, identificando e corrigindo erros de renderização em tempo real.
